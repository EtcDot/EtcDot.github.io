# 现代 CSS 布局完全指南

这是一篇占位示例文章，用来展示博客的文章列表、标签和归档效果。

## 适合使用 Flexbox 的场景

Flexbox 适合一维布局，比如导航栏、按钮组、卡片内部元素对齐。

## 适合使用 Grid 的场景

Grid 适合二维布局，比如仪表盘、作品集、复杂页面骨架。
